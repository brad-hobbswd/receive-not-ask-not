# You Have Not Because You Ask Not

**A Christian book project by Bradley Hobbs**

A devotional and conversation-based exploration of prayer, disappointment, asking for help, and continuing to seek God through uncertainty. Inspired by James 4:2, the book brings personal reflection together with real conversations and lived experience.

[Visit the website](https://brad-hobbswd.github.io/receive-not-ask-not/)
